eTube - Day 1 reference site (HTML only, no CSS yet)
A YouTube-style video site built during the Infosys-sponsored front-end training.

Open index.html with VS Code Live Server (or double-click it).
Pages: index.html (Home + Trending grid), watch.html (video player, description, comments),
       channel.html (channel page + About), upload.html (placeholder until Day 6)
images/ : logo, channel avatar and banner, video thumbnails (placeholders - replace freely)
videos/html-basics.mp4 : 8-second sample clip for the <video> demo (any .mp4 works)
html-notes.pdf : sample file for the download-link demo

Trainer: share images/, videos/ and html-notes.pdf at the start of Day 1;
share the full kit after the lab as the reference solution.
